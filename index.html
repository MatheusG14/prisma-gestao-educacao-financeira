Dados coletados

  • Nome, e-mail e dados de autenticação — para criação e proteção da sua conta

Armazenamento e segurança

Seus dados são armazenados em banco de dados seguro com criptografia. Senhas são derivadas com algoritmo scrypt e nunca armazenadas em texto simples. Sessões utilizam tokens criptograficamente seguros com expiração automática.

Seus direitos (Art. 18, LGPD)

  • Acesso aos seus dados pessoais
  • Correção de dados incompletos ou incorretos
  • Eliminação dos dados tratados com base em consentimento
  • Portabilidade dos dados a outro fornecedor
  • Revogação do consentimento a qualquer momento

Política de Privacidade

Prisma — versão 1.0, novembro de 2026

1. Controlador

A Prisma é a controladora dos dados pessoais tratados nesta plataforma.

2. Dados coletados e finalidades

Dados de conta: nome e e-mail — para autenticação e comunicação.

Dados financeiros: receitas, despesas, contas, investimentos inseridos pelo usuário — para funcionamento das funcionalidades contratadas.

Dados técnicos: endereço IP, agente de usuário — para segurança e prevenção de fraudes.

3. Base legal

O tratamento para operação do sistema é baseado na execução de contrato (Art. 7º, V, LGPD). Comunicações e análise preditiva dependem de consentimento do titular (Art. 7º, I, LGPD).

4. Compartilhamento

Seus dados não são compartilhados com terceiros para fins comerciais. Poderão ser compartilhados com prestadores de serviço de infraestrutura estritamente necessários à operação, sob obrigações de confidencialidade.

5. Retenção

Os dados são mantidos enquanto a conta estiver ativa. Após encerramento, os dados são eliminados no prazo de 30 dias, salvo obrigação legal de retenção.

6. Seus direitos

Você tem o direito de acessar, corrigir, eliminar, portar e revogar consentimento sobre seus dados. Acesse Configurações → Privacidade & LGPD ou fale com a equipe Prisma.

7. Encarregado de Proteção de Dados (DPO)

Contato com o encarregado: fale com o DPO da Prisma

8. Alterações

Esta política pode ser atualizada. Quando houver alterações relevantes, você será notificado e poderá revisar suas escolhas de consentimento.
